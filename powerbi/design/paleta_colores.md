# Paleta de Colores

## Interfaz

| Uso | Color | Hex |
|---|---|---|
| Marron madera | Fondo de menu, titulos fuertes | `#2B1E1A` |
| Borravino principal | Seleccion activa, botones, acentos | `#3E244A` |
| Dorado envejecido | Acentos, lineas, indicadores premium | `#B88646` |
| Crema fondo | Fondo general de paginas | `#F8F5EF` |
| Blanco tarjeta | Cards, tablas, paneles | `#FFFFFF` |
| Texto principal | Lectura principal | `#2D2D2D` |
| Texto secundario | Etiquetas y ayuda | `#6B625C` |

## Datos

| Grupo | Colores |
|---|---|
| Tintos | `#6B1F2A`, `#7A263A`, `#4E1A24` |
| Blancos | `#D8B75A`, `#E8DCA2`, `#B9A44C` |
| Rosados | `#C97B84`, `#D9A0A7` |
| Neutros | `#8C7B6B`, `#A89F91` |

## Estados

| Estado | Color sugerido | Hex sugerido | Uso |
|---|---|---|---|
| Correcto | Verde oliva | `#6F7F3F` | Stock normal, tarea en orden |
| Advertencia | Ambar | `#D69A2D` | Capacidad alta, dato pendiente |
| Error | Rojo vino | `#8A1F2D` | Stock insuficiente, vencido critico |
| Pendiente | Gris calido | `#A89F91` | OT pendiente, sin clasificar |
| Completado | Verde suave | `#8FAF77` | OT completada, proceso cerrado |

## Recomendaciones de uso

- Borravino `#3E244A` identifica interfaz, no variedades.
- Para variedades tintas usar la paleta de tintos, no el borravino principal.
- Dorado debe aparecer poco y con intencion: resaltar, separar o indicar foco.
- Crema debe dominar el fondo general para que el reporte respire.
- No usar mas de 6 colores de datos en un mismo visual.
- Usar neutros cuando una categoria no corresponde a tipo de vino.
- Mantener el mismo color para la misma categoria en todas las paginas.

## Contraste

- Texto oscuro sobre crema o blanco.
- Texto crema/blanco sobre marron madera o borravino.
- Evitar texto dorado sobre crema por bajo contraste.
- En fotos, usar overlay marron con transparencia antes de colocar texto.
